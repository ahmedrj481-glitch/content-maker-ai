صانع المحتوى AI - النسخة التجريبية الأولى

هذه نسخة ويب تقدم واجهة عربية ومسودات أولية تعمل دون حساب أو اشتراك.
لتجربتها:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى استضافة مواقع ثابتة HTTPS (مثل GitHub Pages).
3) افتح رابط الموقع من Chrome على أندرويد.
4) من قائمة Chrome اختر: إضافة إلى الشاشة الرئيسية / تثبيت التطبيق.

مهم:
- هذه النسخة لا تتصل حالياً بنموذج ذكاء اصطناعي؛ النصوص التي تنشئها قوالب أولية وليست توليداً ذكياً.
- لا يوجد فيها بعد تحويل فعلي إلى فيديو أو صورة أو صوت.
- ربط الذكاء الاصطناعي يحتاج اختيار مزود خدمة ومراجعة حدود الاستخدام المجاني، وقد يتطلب مفتاح API.
- لا تضع مفاتيح API السرية داخل ملفات الواجهة المنشورة للعامة.
